# Jobfly

## Register
product

## Platform
web

## Users
The JSON Resume maintainer and curious job seekers experimenting with a fly-controlled search.

## Product Purpose
A fly explores a field of jobs represented as poop. On landing, the person supplies likes, dislikes and optional reasons. Neural learning changes subsequent exploration.

## Positioning
An observable, teachable creature for discovering work, using the full MaleCNS connectome simulation.

## Brand Personality
Playful, beautiful, curious. The user's approved reference is fly.ai's live neural HUD; Three.js is required.

## Design Principles
The landscape is the primary interface. Show real simulated neural activity. Human feedback is the reward. Preserve provenance and distinguish examples from imported jobs.

## Implementation choices
An intimate dusk-lit terrarium viewed on a laptop: a dark surround protects the luminous neural details; soft lavender controls and apricot rewards carry the color. These are implementation choices, not additional user requirements. Keyboard controls, reduced motion and a text-based job list accompany the canvas.
